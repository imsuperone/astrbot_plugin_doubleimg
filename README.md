# 双图插件

```text
/双图 <A> <B>
/双图 ./a.jpg ./b.jpg
/双图 --apng ./a.jpg ./b.jpg
/双图 （后附带两张图一起发）
变量 --apng 
```

作用:用户发双图带图指令后 合成两张图片为一张 默认显示A图 点击加载原图后显示B图 默认输出PNG格式 可带变量 /双图 --apng AB图 实现输出APNG格式 效果一致 过程中会自动压缩图片为1MB以下大小

自带排队 5个进程为上限 不留本地缓存

## 原理

- 两张合成为一张 APNG（PNG 动图扩展，文件里带 `acTL/fcTL` 块）。
- 第 1 帧放 A：聊天列表只显示静止的第一帧，所以看到的是 A。
- 后面放 B（无限循环）：加载原图后显示完整动画持续播放，看到的是 B。
- 以图片消息原图发出（行内预览播动画全端一致；存盘后缀由QQ按内容定）。
